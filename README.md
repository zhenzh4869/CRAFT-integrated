# CRAFT Integrated Modelling Framework

This repository contains the **CRAFT-hourly** and **CRAFT-grid** modules used in the integrated CRAFT modelling framework for analysing low-carbon chemical production, chemical–power interactions, and high-resolution renewable deployment.

The overall framework consists of four linked models:

- **CRAFT-Macro** – long-term chemical transition and spatial layout
- **CHEER-Power** – power-system capacity expansion and dispatch
- **CRAFT-hourly** – hourly chemical capacity expansion and operation
- **CRAFT-grid** – high-resolution renewable siting and chemical–power interconnection

These modules are linked sequentially so that long-term industrial restructuring, hourly operational flexibility, power-system feedback, and spatial renewable deployment can be analysed within a consistent framework.

## Model framework

### 1. CRAFT-Macro

**CRAFT-Macro** determines long-term chemical-sector transition pathways at the provincial level. It optimizes production structure, technology routes, capacity expansion, interprovincial product flows, and industrial spatial layout under product-demand, resource, cost, and carbon-emission constraints.

CRAFT-Macro provides the provincial production structure, technology mix, and chemical demand used by the downstream hourly model.

The CRAFT-Macro model is available at:

https://github.com/zhenzh4869/CRAFT-model.git

### 2. CHEER-Power

**CHEER-Power** represents the provincial power system. It optimizes power-sector capacity expansion and hourly dispatch under electricity-demand, resource, operational, transmission, and carbon constraints.

In the integrated workflow, CHEER-Power provides electricity-system boundary conditions, including hourly electricity prices, grid-emission intensities, load profiles, and power-system operating conditions. The electricity purchase and sale profiles generated by CRAFT-hourly can then be passed back to CHEER-Power to evaluate their impacts on power-system investment, dispatch, emissions, and total system cost.

The CHEER-Power model is available at:

https://github.com/KennethAnn/CHEER-Power

### 3. CRAFT-hourly

**CRAFT-hourly** is an hourly capacity-expansion and operation model for low-carbon chemical production systems. It resolves a full **8,760-hour annual chronology** and optimizes the deployment and operation of dedicated wind and solar generation, electrolysers, hydrogen storage, batteries, synthesis facilities, and optional hydrogen-to-power generation.

Grid interaction is represented through hourly electricity purchases and sales. Different assumptions on production flexibility and grid interaction can therefore be used to evaluate how chemical production responds to renewable variability and electricity-system conditions.

CRAFT-hourly takes the production demand and spatial structure from CRAFT-Macro together with power-system boundary conditions from CHEER-Power, and generates hourly chemical production, electricity purchase and sale, storage operation, and other system-operation results.

### 4. CRAFT-grid

**CRAFT-grid** translates provincial renewable deployment and cross-sector electricity-transfer requirements into spatially explicit renewable siting and interconnection results.

The model contains two spatial layers:

1. A **50 km mixed-integer optimization model** allocates onshore wind, solar PV, and offshore wind capacity between the chemical and power sectors and matches renewable generation with sectoral load centres.
2. A **1 km downscaling procedure** further allocates land-based wind and solar capacity using pixel-level resource suitability, installable potential, and LCOE.

CRAFT-grid therefore links provincial deployment requirements with renewable-resource locations, chemical and power load centres, and chemical-to-power transmission connections.

## Model linkage

A simplified workflow is:

**CRAFT-Macro → CHEER-Power → CRAFT-hourly → CHEER-Power → CRAFT-grid**

CHEER-Power first provides electricity-system boundary conditions to CRAFT-hourly. The hourly electricity purchase and sale profiles generated by CRAFT-hourly are then passed back to CHEER-Power for power-system re-optimization.

In brief, CRAFT-Macro determines **what and where to produce**, CHEER-Power characterizes **power-system conditions**, CRAFT-hourly determines **how the chemical system operates hour by hour**, and CRAFT-grid determines **where renewable assets and cross-sector connections are spatially deployed**.

## Files in this repository

This repository provides both **Jupyter Notebook (`.ipynb`)** and **Python script (`.py`)** versions of the CRAFT-hourly and CRAFT-grid models.

The two versions implement the same model logic. The notebook versions are convenient for interactive inspection and testing, while the Python scripts are more suitable for batch execution and high-performance computing environments.

On an **Intel(R) Core(TM) i9-14900HX (2.20 GHz)** processor, one scenario takes approximately **29 hours** to run and requires **more than 40 GB of memory**. To facilitate model testing and reproduction, this repository therefore provides only the **single-province Xinjiang version** of the model.
